# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: static HTML/CSS/JS for a fast, dependency-free personal site.

## Users

People and teams who need a mobile app, web app, website, code fix, integration, or a stronger next version of an existing product.

## Product Purpose

The site makes Yonatan's offer immediately legible, explains the main development and debugging services, names three engagement shapes, and gives a visitor one clear way to start a conversation.

## Positioning

Inferred from the brief and reference site: a hybrid product, design, and code practice that turns tangled ideas into clear digital experiences through focused decisions and close collaboration.

## Operating Context

Visitors arrive from a shared link, understand what can be built or fixed from the hero, scan capabilities and engagement shapes, check fit and practical answers, then send a short project inquiry.

## Capabilities and Constraints

The site needs a responsive focused one-page presentation, minimal section navigation, accessible semantic content, engagement guidance without prices, a small note row, a practical FAQ, a qualified inquiry form ready for a future POST endpoint, metadata for sharing and search, and no invented customer proof or quantitative claims.

## Brand Commitments

The user explicitly referenced m3rkl.com as the visual model. The working name for this build is Yonatan, supplied in the project conversation.

## Evidence on Hand

The reference site at https://m3rkl.com/ was inspected for layout, copy rhythm, and interaction patterns. No personal portfolio assets or verified case studies were supplied, so the site uses authored positioning copy and one custom product object instead of work examples.

## Product Principles

- Make the audience, outcome, and next action legible within seconds.
- Show how the work can be shaped before asking for commitment.
- Name useful outputs instead of inventing proof.
- Use specific, calm language instead of hype.
- Keep the first contact qualified but lightweight.
